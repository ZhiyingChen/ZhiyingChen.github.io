01 / PROBLEM

多型号订单，如何排出
更好的生产节奏？

04 / METHODOLOGY

把复杂约束，变成可比较的选择。

从原项目提取混线生产的核心逻辑，在浏览器中探索不同生产序列的影响。

这是独立的简化交互模型。原 Python / Pyomo 工业模型保留，原始物料齐套、组装/包装跨工序衔接、规格匹配、设备集群均衡和集合覆盖 MIP 未在此版复现。
01

生成可行的每日安排

每线每天一个型号。启动后满足最少连续运行；临近计划末端，无法满足完整运行期的新任务不再启动。

02

计算爬坡后的有效产能

连续生产使产能逐日恢复，空闲中断后重启重新爬坡。每次跨型号切换叠加当天换型损耗。

03

保留有潜力的候选序列

束搜索每天保留有限候选：平衡优先级加权欠交件天、换型惩罚、少量提前生产代价及期末欠交惩罚。搜索宽度更大通常探索更多方案。

04

汇总交付与产线安排

输出可执行约束下的候选方案；属于启发式搜索，不提供全局最优性保证。利用率按产出 / 全部额定产能计算；按时交付率按件数计算。
