01 / EQUIPMENT

设备开启后，不能随意停机

限制每日开机数量的变化，并要求新开设备连续运行指定天数。已运行设备按满产计算。

02 / MATERIAL FLOW

切片需要前一天留下的材料

切片消耗期初在制品；拉晶产出次日可用。成品产出按「成品率 ÷ 成晶率」换算。

03 / DELIVERY

交期优先，同时观察库存

交期当天起按先到期订单交付，欠交可后续补齐。安全库存作为软目标，缺口会单独报告。

交互版使用单产品、固定日产能和良率的有限宽度束搜索，演示原项目的核心业务规则。原工业模型采用 Pyomo 混合整数规划，含更多库存点、月度参数与组织均衡约束。此处示例与历史项目 KPI 无关。

04 / METHODOLOGY

把复杂规则，变成可比较的每日决策。

原 Python 模型扩展 SCP 的 MPS 框架，以整数开机数量、库存流平衡和分层目标求解。网页使用独立 JavaScript 演示引擎，全部数据在本机处理。

本版不包含多产品、月度工艺参数、运输网络或同组织设备均衡，也不保证全局最优。搜索未找到方案不等于数学上无解。

01

枚举每日开机数量

根据设备上限、启停上限、连续运行队列生成候选，禁止新开设备在计划期末越界运行。

02

校验物料与满产规则

切片满产用料不得超过期初在制品；新开切片首日打折。拉晶当天产出在次日可用。

03

交付订单并评价候选

按交期顺序分配成品。综合累计欠交、期末未交、安全库存缺口、持有量和启停台次评分；安全库存为软目标。

04

保留较优候选，滚动展开

每一天只保留有限数量候选。结果是启发式计划，搜索宽度影响时间与质量；完整结果记录本次输入。
