04 / METHODOLOGY

沿用工艺公式，
把比值转成线性规划

原项目使用 SciPy SLSQP 与 basinhopping。网页对当前单批次连续配比问题采用 Charnes–Cooper 变换与两阶段单纯形法，在数值容差内求解线性规划，再用原始公式逐项复核。结果仅对应当前输入与模型假设。

01

计算干基和烧存

dᵢ = 1 − 水分ᵢ / 100；rᵢ = dᵢ × (1 − 烧损ᵢ / 100)。配比 xᵢ 以 0–1 计，总烧存 R = Σxᵢrᵢ。

02

组成与成本

成分百分比 Aⱼ = Σ[xᵢdᵢaᵢⱼ(1−脱除率ⱼ)] / R；成本 = Σxᵢdᵢ价格ᵢ / R。比值采用脱除后的成分含量。

03

等价变换

令 yᵢ = xᵢ / R，使 Σrᵢyᵢ = 1；配比上下限变为 lᵢΣy ≤ yᵢ ≤ uᵢΣy。分母为正时，比值边界可交叉相乘变成线性不等式。

04

还原并验证

xᵢ = yᵢ / Σy。使用原始公式检查每项边界，绝对容差 10⁻⁵；配比和容差 10⁻⁶。不提供当前约束下不可行的“最优”方案。
