生产批量与计算口径

批量只影响吨数与总成本，不改变最优配方。

吨铁成本 = 干基均价 ÷ (TFe / 100)

干基价 = 湿基价 ÷ (1 − 水分 / 100)。湿基采购吨数由干基用量反推；混合水分按湿基加权。

04 / METHODOLOGY

沿用业务公式，
把优化带到浏览器。

网页沿用原项目的干湿基换算、成分加权与吨铁成本目标。当前演示覆盖六项成分，不含原 Excel 中的其他微量元素。

01

干配比是决策变量

各矿干配之和为 100%，每种矿都受使用比例上下限约束。

02

水分约束也能线性化

非水成分按干基加权；水分按湿基加权。将水分边界移项，得到等价的线性不等式。

03

线性分式 → 线性规划

所有原料 TFe > 0，使用 Charnes–Cooper 变换和两阶段单纯形求解当前连续配比模型，再核验原始约束，数值容差为 10⁻⁵ 个百分点。

04

网页与原项目的边界

原 Python 采用初始解 + SLSQP / basinhopping；网页使用等价目标的 LP 方法，并将原代码「干基价 / TFe 百分数」乘 100，显示元/吨铁。无整数投料、库存、烧结过程或多方案搜索。
