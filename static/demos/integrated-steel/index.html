01

要决定什么？

4 种矿粉的烧结投料比例、两类球团的组合，以及烧结矿 / 球团矿 / 块矿的入炉比例。

02

什么限制了决策？

原料可用比例、矿仓数量、入炉铁品位、SiO₂ 上限、碱度区间及高炉熔剂用量。

03

最终比较什么？

按铁平衡估计吨铁矿耗，计入矿料、焦炭、喷煤、熔剂与工序费用，选择网格内最低成本的可行方案。

演示范围本站使用虚构数据与简化离散模型，5% 网格搜索不等同于原项目 SLSQP；原项目包含完整成分平衡、返粉与业务校验。演示结果用于理解决策关系，不作为生产配方。

04 / METHODOLOGY

同一条业务链，
两种计算层次。

浏览器演示强调透明和可复现。完整模型通过独立 Python 服务执行，保留原有 Grid / GRASP + SLSQP 算法。

01

生成物料组合

演示枚举矿粉 5% 网格，筛除超出比例上限或矿仓数的组合；完整模型搜索活跃物料集合。

02

串联烧结与炼铁

演示用质量加权、固定收得率和简化铁平衡计算矿耗。焦耗 = 340 + max(0, 62−Fe%)×8 + SiO₂%×3 kg/t；喷煤固定 150 kg/t。熔剂调节至碱度区间中点，用量不得超过 0.25 t/t铁。

03

检查可行性，再比较成本

演示烧结矿入炉占 50–80%、球团 10–40%、块矿 0–20%。优先满足质量约束，再比较已枚举方案成本；不声称连续域全局最优。参考方案固定矿粉 40/40/20/0、普通球团、炉料 60/30/10，可能不满足当前约束。

04
